# 本地飞书扩展

基于本机已安装的 `@michengai/dsh-im-connect` 1.0.8，保留原包许可证和现有功能。

- 全部飞书普通回复使用原生 `text` 消息；审批与按钮选择仍使用交互卡片。Lark 与其他渠道沿用原逻辑。
- 可选连接 `dsh-task-personas` 的 `taskPersonaMedia` 服务，复用现有 SDK 与凭据发送图片/GIF，以及机器人已收到的原生表情。
- 收到的图片/GIF、原生表情进入该会话的候选列表，由用户手动收藏；未收藏时 AI 无权复用。
- 源改动位于 `src/channels/feishu.ts` 与 `src/channels/factory.ts`，编译到 `lib/channels/`；`src/index.ts` / `lib/index.js`、`client.js` / `lib/client.js` 关闭上游更新器注册，避免覆盖本地扩展。
- 原安装目录未原地修改。此本地版本需要保留本目录；升级上游前应重新合并上述改动。

上游更新不包含这些本地能力，请勿用上游更新器直接覆盖此本地扩展。

## 1.0.8-personas.6

- 公开安装包显式声明运行时 `@deepseek-ai/schemastery` 依赖，避免只依赖开发者机器上的链接。

- 接收已选群机器人的 `app` / `bot` 消息，先由人格服务检查群绑定、身份别名及22:00至次日08:00时段；只交给群观察，不进入普通用户任务处理。
- 群历史提取机器人身份、名称及有界文字片段；通过 `user_card_content` 读取新版卡片正文。实时收到已选机器人卡片时按消息ID读取正文，并再次验证群、发送者和时段；自身消息排除，未选机器人不进入模型上下文。复用现有SDK，无新增凭据。

## 1.0.8-personas.5

- 为当前绑定群提供机器人身份的有界历史读取；严格检查群 ID、首次接入时间、分页和发送者类型，缺权限时只返回脱敏错误。

## 1.0.8-personas.4

- 将未 @ 的用户群消息交给可选人格观察服务，仅已绑定且单独开启的群会话处理；不作为普通用户工作指令。机器人回声被忽略，旁观不下载附件。
- @ 机器人消息移除飞书占位键；仅 @ 时提供清晰群聊提醒。后台唤醒前等待人格工具就绪。

## 1.0.8-personas.3

- 关闭全部飞书会话自动附加的 OnIt / DONE / ERROR 消息状态回应。保留正常回复、表情包发送和其他渠道原有状态反馈；历史回应不会批量撤回。

## 1.0.8-personas.2

- 可选人格运行接口通过既有 IM 会话路由恢复并唤醒指定会话；忙碌、审批、断连、静音和绑定变化时跳过。
- 后台恢复读取会话已保存的模型与推理等级，保留 WorkBuddy 等显式选择；读取失败时暂缓恢复，不创建替代会话。
- 飞书人格工具协议下不转发模型普通叙述；根据持久化有效系统提示词恢复协议，历史补发也不发送草稿。
- 增加绑定目标的原生文本发送接口，保留全部原有渠道权限与审批逻辑；普通非人格任务不变。

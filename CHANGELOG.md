# Changelog

## 0.7.0

- First public source release, with companion IM Connect `1.0.8-personas.6`.
- Per-session whale/tsundere roles and native DSH controls; new sessions default off.
- Feishu native text, local sticker collection, tool-based sending and idle social opportunities.
- Opt-in group participation reads all received human messages and selected bot messages without random sampling or group wake quotas.
- Separate unread batches preserve input while the model is busy and when a direct mention cancels a draft.
- Bot quiet time from 22:00 to 08:00 in Asia/Taipei, including checks immediately before sending; humans remain available.
- Public sources and tests contain synthetic fixtures; local QA, credentials, captures, chat logs, personal assets and machine installation state are excluded.
